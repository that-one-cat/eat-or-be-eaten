# 🐟 Eat Or Be Eaten

Игра Роберта, сделана на **Godot 4**.

Ты — рыбка на рифе: ешь тех, кто меньше тебя, и уплывай от тех, кто больше. Иначе съедят тебя!

## 🎮 Как поиграть (папа, это для тебя)

1. Справа на этой странице найди раздел **Releases**
2. Откри **v1.0** и скачай файл **FishGame.exe**
3. Если Windows покажет синее окошко с предупреждением — нажми **«Подробнее» → «Выполнить в любом случае»** (игра собрана дома, она безопасная)
4. Запускай и играй!

## 🛠 Для разработчиков

Исходники игры лежат в папке `game/`. Открой `game/project.godot` в Godot 4 и нажми **F5** — игра запустится.
